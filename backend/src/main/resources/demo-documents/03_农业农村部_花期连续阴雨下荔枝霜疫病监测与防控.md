# 花期连续阴雨下荔枝霜疫病监测与防控

来源机构：农业农村部热带作物病虫害监测与防控项目
发布日期：2022-03-31
原始链接：https://nkj.moa.gov.cn/rzny/202203/t20220331_6394879.htm

- 雨季管理

## 摘要
农业农村部指出，荔枝花穗在连续阴雨和高湿条件下极易感霜疫病，严重时可导致大量小花甚至整穗腐烂。监测时可直接观察褐变小花是否长出白色霉状物；若现场不明显，可通过保湿后再观察。农业措施重点是疏花、通风透光、抬高近地枝叶和雨后摇落水珠与残败小花，化学防控则要求结合果园监测情况及时控制发病中心。

## 可用于问答的知识点
- 花穗褐变并伴白色霉状物，是霜疫病的重要识别线索。
- 连续阴雨、高湿和近地枝条过低，都会增加病害快速蔓延风险。
- 雨后摇花、剪除近地枝条和保证通风透光，是非药剂管理的关键动作。
- 在高温条件下，炭疽病也可能与霜疫病复合发生。

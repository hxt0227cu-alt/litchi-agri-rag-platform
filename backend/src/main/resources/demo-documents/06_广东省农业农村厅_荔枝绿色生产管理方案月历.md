# 荔枝绿色生产管理方案月历

来源机构：广东省农业农村厅
发布日期：2023-02-01
原始链接：https://dara.gd.gov.cn/ywdt/nstt/content/post_4542110.html

## 适用标签
- 绿色生产
- 月历管理
- 花穗期
- 开花期
- 保花保果

## 摘要
广东省农业农村厅发布的荔枝绿色生产月历，按月份和早熟/中迟熟品种分别给出物候期与管理重心。花穗期强调促抽健壮花穗和控梢促花；开花期强调授粉、保花保果、控制春梢和防止“沤花”；月历还把炭疽病、霜疫病、尺蠖、卷叶蛾、蒂蛀虫等高发对象纳入不同月份的管理提示中。

## 可用于问答的知识点
- 荔枝管理要跟着月份和物候期走，不能把花期、幼果期、膨果期混为一谈。
- 花穗期和开花期要兼顾营养、授粉、控梢与病虫害综合管理。
- 雨天和花期管理不当会增加“沤花”和病害侵染风险。
- 适合回答“花果期怎么管理”“为什么不同月份重点不同”等问题。

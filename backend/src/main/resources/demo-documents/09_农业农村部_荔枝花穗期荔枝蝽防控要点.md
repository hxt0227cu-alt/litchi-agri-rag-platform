# 荔枝花穗期荔枝蝽防控要点

来源机构：农业农村部热带作物病虫害监测与防控项目

- 落花落果

## 摘要
农业农村部指出，荔枝蝽成虫与若虫都会以刺吸式口器为害荔枝嫩梢、花穗和幼果，造成黄褐色伤口斑点，并为病菌侵入创造条件。严重时会带来大量落花、落果甚至失收。对于桂味、糯米糍等中晚熟品种，花穗期正是重点防控窗口，宜加强巡园、人工捕捉和摘除卵块。

## 可用于问答的知识点
- 荔枝蝽为害部位包括嫩梢、花穗和幼果，不是只危害成熟果。
- 刺吸伤口会提高病菌侵入机会，因此虫害与病害管理往往要联动考虑。
- 花穗期是重要监测和人工处理窗口。
- 适合回答“花穗期要防什么虫”“为什么虫害也会加重病害风险”等问题。

# 答辩演示说明

## 一键启动

在项目根目录执行：

```powershell
.\scripts\run-demo.ps1
```

如果你想在启动前重新构建一次前后端，可以执行：

```powershell
.\scripts\run-demo.ps1 -Build
```

启动完成后，默认访问地址为：

- 前端演示页：`http://127.0.0.1:5173`
- 后端健康检查：`http://127.0.0.1:8080/api/health`
- 识别服务健康检查：`http://127.0.0.1:8090/health`

演示结束后执行：

```powershell
.\scripts\stop-demo.ps1
```

## 推荐演示顺序

1. 进入“系统总览”，说明系统包含知识文档、知识图谱、智能问答和病害识别四个模块。
2. 进入“知识文档”，展示系统已经自动准备好的答辩样例文档，也可以现场上传新的 txt 或 md 文档。
3. 进入“智能问答”，直接点击推荐问题，展示回答、来源文档片段和图谱命中实体。
4. 进入“知识图谱”，搜索“桂味”或“炭疽病”，展示品种、病害、药剂和技术的关系链路。
5. 进入“病害识别”，直接点击内置样图完成演示；如果现场条件允许，也可以上传自己的叶片图片。

## 当前默认演示模式

- 问答模块：即使 Ollama 不在线，也会自动使用本地答辩模式生成可解释回答。
- 图谱模块：即使 Neo4j 不在线，也会使用内置演示图谱。
- 检索模块：即使 Milvus 不在线，也会回退到本地向量与切片检索。
- 识别模块：如果 `models/yolov8-litchi.pt` 不存在，会自动回退到数据集特征匹配模式。

## YOLO 模型说明

识别服务已经支持自动加载 YOLO 权重文件。只要你把模型文件放到以下路径：

```text
models/yolov8-litchi.pt
```

下次启动 `diagnosis-service/server.py` 时就会自动切换到 `ultralytics-yolo` 模式。

当前仓库已经包含 `models/yolov8-litchi.pt` 权重文件。若本机已安装 `ultralytics` 依赖，识别服务会优先使用 YOLO 推理；若依赖缺失或模型加载失败，则会自动回退到演示模式，不影响答辩流程。

### 1.2 关系类型（Relationships）

| 关系类型 | 起点 | 终点 | 属性 | 说明 |
|---------|------|------|------|------|
| HAS_DISEASE | LitchiVariety | Disease | severity | 品种易患病害 |
| HAS_PEST | LitchiVariety | Pest | severity | 品种易患虫害 |
| TREATS | Pesticide | Disease/Pest | - | 农药防治对象 |
| PREVENTS | Pesticide | Disease/Pest | - | 农药预防对象 |
| NEEDS_TECHNIQUE | LitchiVariety | CultivationTechnique | - | 品种需要的技术 |
| SIMILAR_TO | Disease/Pest | Disease/Pest | - | 相似病害/虫害 |

### 1.3 Cypher 查询示例

#### 1.3.1 查询品种的病害
```cypher
MATCH (v:LitchiVariety {name: '桂味'})-[:HAS_DISEASE]->(d:Disease)
RETURN v.name, d.name, d.symptom
```

#### 1.3.2 查询病害的防治农药
```cypher
MATCH (d:Disease {name: '霜疫霉病'})<-[:TREATS]-(p:Pesticide)
RETURN d.name, p.name, p.usage
```

#### 1.3.3 查询相关子图
```cypher
MATCH (v:LitchiVariety {name: '桂味'})
MATCH path = (v)-[*1..2]-()
RETURN path
```

## 4. 数据初始化

### 4.1 知识图谱初始化

```java
@Service
public class KnowledgeGraphInitializer {
    
    @Autowired
    private Driver neo4jDriver;
    
    public void init() {
        try (Session session = neo4jDriver.session()) {
            // 创建索引
            session.run("CREATE INDEX IF NOT EXISTS FOR (v:LitchiVariety) ON (v.name)");
            session.run("CREATE INDEX IF NOT EXISTS FOR (d:Disease) ON (d.name)");
            session.run("CREATE INDEX IF NOT EXISTS FOR (p:Pest) ON (p.name)");
            session.run("CREATE INDEX IF NOT EXISTS FOR (pe:Pesticide) ON (pe.name)");
            
            // 初始化示例数据
            initSampleData(session);
        }
    }
}
```

### 4.2 向量数据库初始化

```java
@Service
public class VectorStoreInitializer {
    
    @Autowired
    private MilvusClient milvusClient;
    
    public void init() {
        // 创建Collection
        if (!milvusClient.hasCollection("litchi_knowledge")) {
            milvusClient.createCollection(
                CollectionSchema.newBuilder()
                    .withName("litchi_knowledge")
                    .addFieldType(FieldType.newBuilder()
                        .withName("id")
                        .withDataType(DataType.VARCHAR)
                        .withMaxLength(64)
                        .withPrimaryKey(true)
                        .build())
                    .addFieldType(FieldType.newBuilder()
                        .withName("vector")
                        .withDataType(DataType.FLOAT_VECTOR)
                        .withDimension(1024)
                        .build())
                    .build()
            );
            
            // 创建索引
            milvusClient.createIndex(
                "litchi_knowledge",
                "vector",
                IndexParam.newBuilder()
                    .withIndexType(IndexType.IVF_FLAT)
                    .withMetricType(MetricType.IP)
                    .withExtraParam("{\"nlist\": 1024}")
                    .build()
            );
        }
    }
}
```

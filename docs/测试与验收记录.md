## 当前版本已验证项

### 1. 工程构建

- 前端 `npm test` 通过
- 前端 `npm run build` 通过
- 后端 `mvn -q test` 通过
- 后端 `mvn -q -DskipTests package` 通过

### 2. 功能闭环

- 账号登录、角色权限与受限路由已存在自动校验
- 智能问答支持来源卡片与历史会话回放
- 知识图谱支持可视化、实体搜索、关系详情和关联跳转
- 病害识别支持 YOLO 模型优先加载，并保留降级模式
- 技术员培训课堂、农资店用药指南、满意度问卷已补齐
- 系统设置页与满意度统计接口已纳入当前实现

### 3. 自动化测试覆盖

- 后端 smoke test 已覆盖认证、评测、文档上传、满意度问卷、健康检查和角色权限
- 前端访问控制测试已覆盖技术员、农户、农资店主的关键权限判断

### 4. 可演示性

- 仓库已包含 `models/yolov8-litchi.pt`
- Docker 与本机模式都保留了图谱、问答、识别的降级保障路径
- 页面已补充培训课堂、用药指南和满意度问卷，适合答辩串讲

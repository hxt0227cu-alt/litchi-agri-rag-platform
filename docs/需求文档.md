# 需求文档

## 1. 项目背景

随着人工智能技术的发展，将大模型、知识图谱和RAG技术应用于农业领域具有重要意义。荔枝是中国南方重要的经济作物，但荔枝种植过程中面临病虫害识别困难、专业知识获取不便等问题。

本项目旨在构建一个基于大模型RAG-知识图谱的荔枝智能问答Web平台，为荔枝种植者提供便捷、专业的技术咨询服务。

## 2. 项目目标

- 构建荔枝种植领域知识图谱
- 实现基于RAG+知识图谱的智能问答
- 提供拍照识病功能
- 支持语音问答
- 实现本地部署，离线可用

## 3. 用户角色

| 用户角色 | 核心需求 |
|---------|---------|
| **农民** | 拍照识病、语音问答、简单易用 |
| **农技员** | 数据大屏、来源追溯、培训课堂 |
| **农资店主** | 快速配药、用药指南 |

## 4. 功能需求

### 4.1 智能问答模块

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 文本问答 | 支持自然语言提问 | P0 |
| 多轮对话 | 支持上下文理解 | P1 |
| 答案来源 | 显示答案参考来源 | P1 |

### 4.2 拍照识病模块

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 图片上传 | 支持上传荔枝叶片/果实照片 | P0 |
| 病害识别 | 自动识别病虫害类型 | P0 |
| 置信度显示 | 显示识别结果置信度 | P1 |
| 防治建议 | 提供相应的防治建议 | P0 |

### 4.3 语音问答模块

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 语音输入 | 支持语音转文字 | P1 |
| 语音播报 | 支持文字转语音 | P1 |

### 4.4 知识图谱模块

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 图谱可视化 | 知识图谱图形化展示 | P1 |
| 实体搜索 | 搜索图谱中的实体 | P1 |
| 关系查询 | 查询实体间的关系 | P1 |

### 4.5 知识库管理

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 文档上传 | 支持上传PDF/Word文档 | P1 |
| 文档列表 | 查看已上传的文档 | P1 |
| 文档删除 | 删除不需要的文档 | P2 |

### 4.6 系统管理

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 用户登录 | 基础用户认证 | P2 |
| 对话历史 | 查看历史对话记录 | P1 |
| 系统设置 | 配置系统参数 | P2 |

## 5. 非功能需求

### 5.1 性能需求

| 指标 | 要求 |
|------|------|
| 问答响应时间 | &lt; 5秒（平均） |
| 图像识别时间 | &lt; 3秒 |
| 并发用户数 | 支持50+并发用户 |
| 系统可用性 | &gt; 99% |

### 5.2 安全需求

- 用户数据加密存储
- 农药剂量安全校验
- 系统操作日志记录

### 5.3 兼容性需求

- 支持主流浏览器（Chrome、Firefox、Edge、Safari）
- 支持移动端访问
- 支持Windows/Linux部署

### 5.4 可扩展性需求

- 模块化设计，便于功能扩展
- 支持新增荔枝品种和病虫害
- 支持模型版本更新

## 6. 数据需求

### 6.1 知识图谱数据

| 实体类型 | 预计数量 |
|---------|---------|
| 荔枝品种 | 20+ |
| 病害 | 50+ |
| 虫害 | 30+ |
| 农药 | 100+ |
| 栽培技术 | 50+ |

### 6.2 文档数据

- 荔枝种植技术文档（PDF格式）
- 预计文档数量：50+
- 总数据量：1GB+

- 训练集：2000+ 张
- 验证集：200-300 张
- 测试集：200-300 张

## 7. 评测需求

### 7.1 评测集设计

| 问题类型 | 数量 |
|---------|------|
| 品种介绍 | 15 |
| 种植技术 | 20 |
| 病害识别 | 25 |
| 虫害防治 | 20 |
| 农药使用 | 10 |
| 综合问题 | 10 |
| **总计** | **100** |

- **BLEU-4**: 自动评价生成答案质量

- 预算限制：学生项目，无额外经费

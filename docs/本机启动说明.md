# 本机启动说明

本文档用于在不依赖 Docker 前端/后端容器的情况下，本机启动荔枝智能诊断平台。

## 1. 前置依赖

请先确保以下服务已经可用：

- MySQL 8
- Neo4j 5
- Milvus 2.3
- Ollama
- `diagnosis-service`

推荐优先参考 [环境安装指南](./环境安装指南.md) 完成准备。

## 2. 启动顺序

### 2.1 启动基础依赖

确认以下地址可访问：

- MySQL：`127.0.0.1:3306`
- Neo4j：`127.0.0.1:7687`
- Milvus：`127.0.0.1:19530`
- Ollama：`http://127.0.0.1:11434`
- 识别服务：`http://127.0.0.1:8090`

### 2.2 准备 Ollama 模型

```bash
ollama pull qwen2.5:0.5b
```

### 2.3 启动病害识别服务

```bash
cd diagnosis-service
pip install -r requirements.txt
python server.py
```

如果没有正式模型文件，服务会运行在保障模式。

### 2.4 启动后端

```bash
cd backend
mvn spring-boot:run
```

如果你希望本机启动后自动完成图谱、向量和样例文档准备，可以先设置：

```powershell
$env:APP_STARTUP_AUTO_BOOTSTRAP='true'
```

然后再执行：

```powershell
mvn spring-boot:run
```

如果你只想手动初始化图谱和向量，也可以使用：

```bash
mvn spring-boot:run -Dspring-boot.run.arguments="--init=all"
```

### 2.5 启动前端

```bash
cd frontend
npm install
npm run dev
```

启动后访问：

- 前端：`http://localhost:5173`
- 后端：`http://localhost:8080/api`

## 3. 默认账号

- `farmer / demo123`
- `technician / demo123`
- `shopkeeper / demo123`

## 4. 首次使用建议

如果本机没有开启 `APP_STARTUP_AUTO_BOOTSTRAP=true`，建议第一次启动按下面顺序操作：

1. 使用技术员账号登录前端。
2. 进入总览页或文档页，点击“初始化平台样例”。
3. 再进入问答页、图谱页和识别页进行验证。

## 5. 本机验证流程

推荐按以下顺序检查：

1. 登录平台，确认首页可打开。
2. 在文档页确认存在平台样例文档。
3. 在问答页输入“荔枝炭疽病如何防治”，确认有来源卡片。
4. 在图谱页搜索“炭疽病”，确认能看到实体列表和详情。
5. 在识别页上传样图，确认能返回识别结果。
6. 使用技术员账号进入评测页，确认题库可加载。

## 6. 手动接口验证

### 6.1 健康检查

```bash
curl http://localhost:8080/api/health
```

### 6.2 手动初始化图谱与向量

如果你已经拿到技术员登录 Token，可以调用：

```bash
curl -X POST "http://localhost:8080/api/system/init?scope=all" ^
  -H "Authorization: Bearer <token>"
```

### 6.3 手动重建平台样例

```bash
curl -X POST "http://localhost:8080/api/system/demo/bootstrap" ^
  -H "Authorization: Bearer <token>"
```

## 7. 常见说明

- 文档上传当前支持 `txt`、`md`、`pdf`、`docx`。
- 本机开发默认是前后端分开运行，角色权限仍然完整生效。
- 如果 Milvus 未命中，问答仍会回退到本地分块检索。
- 如果识别模型不可用，识别服务会进入保障模式。

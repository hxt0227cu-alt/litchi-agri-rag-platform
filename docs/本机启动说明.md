# 本机启动说明

## 依赖

- Java 17
- Maven 3.9+
- Node.js 20+
- Neo4j 5.x
- Milvus 2.3.x
- Ollama

## 后端

```bash
cd backend
mvn spring-boot:run
```

初始化：

```bash
curl -X POST "http://localhost:8080/api/system/init?scope=all"
```

或：

```bash
mvn spring-boot:run -Dspring-boot.run.arguments="--init=all"
```

## 前端

```bash
cd frontend
npm install
npm run dev
```

## 演示顺序

1. 先初始化系统。
2. 上传一份 `txt` 或 `md` 文档。
3. 在智能问答页提问并展示来源卡片。
4. 在知识图谱页搜索“炭疽病”或“桂味”。
5. 在拍照识病页上传示例图片展示结果。

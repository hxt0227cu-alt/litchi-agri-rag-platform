# 部署文档

## 1. 环境要求

### 1.1 硬件要求

| 配置 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 4核 | 8核以上 |
| 内存 | 16GB | 32GB以上 |
| 硬盘 | 100GB | 200GB以上 |
| GPU | - | NVIDIA GPU (8GB+显存) |

### 1.2 软件要求

- Docker 24.0+
- Docker Compose 2.20+
- Git (可选)
- NVIDIA Container Toolkit (可选，用于GPU加速)

---

## 2. 快速部署

### 2.1 克隆项目

```bash
git clone https://github.com/yourusername/litchi-qa-platform.git
cd litchi-qa-platform
```

### 2.2 配置环境变量

复制环境变量模板：

```bash
cp .env.example .env
```

编辑 `.env` 文件：

```env
# Neo4j 配置
NEO4J_AUTH=neo4j/litchi123456
NEO4J_dbms_memory_pagecache_size=1G
NEO4J_dbms_memory_heap_initial__size=2G
NEO4J_dbms_memory_heap_max__size=4G

# Milvus 配置
MILVUS_HOST=milvus
MILVUS_PORT=19530

# Ollama 配置
OLLAMA_URL=http://ollama:11434
OLLAMA_MODEL=qwen2.5:7b

# 后端配置
SPRING_PROFILES_ACTIVE=prod
SERVER_PORT=8080
```

### 2.3 启动服务

```bash
# 一键启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f
```

### 2.4 初始化数据

```bash
# 进入后端容器
docker-compose exec backend bash

# 初始化知识图谱和向量数据库
java -jar app.jar --init

# 或者通过API初始化
curl -X POST http://localhost:8080/api/system/init
```

### 2.5 拉取大模型

```bash
# 进入Ollama容器
docker-compose exec ollama bash

# 拉取Qwen2.5-7B模型
ollama pull qwen2.5:7b

# 测试模型
ollama run qwen2.5:7b
```

## 4. Docker Compose 配置详解

### 4.1 docker-compose.yml

```yaml
version: '3.8'

services:
  # Neo4j 知识图谱数据库
  neo4j:
    image: neo4j:5.15-community
    container_name: litchi-neo4j
    environment:
      - NEO4J_AUTH=${NEO4J_AUTH:-neo4j/litchi123456}
      - NEO4J_dbms_memory_pagecache_size=${NEO4J_PAGECACHE_SIZE:-1G}
      - NEO4J_dbms_memory_heap_initial__size=${NEO4J_HEAP_INIT:-2G}
      - NEO4J_dbms_memory_heap_max__size=${NEO4J_HEAP_MAX:-4G}
    ports:
      - "7474:7474"
      - "7687:7687"
    volumes:
      - neo4j_data:/data
      - neo4j_logs:/logs
    networks:
      - litchi-network
    restart: unless-stopped

  # Milvus 向量数据库依赖 - etcd
  etcd:
    image: quay.io/coreos/etcd:v3.5.5
    container_name: litchi-etcd
    environment:
      - ETCD_AUTO_COMPACTION_MODE=revision
      - ETCD_AUTO_COMPACTION_RETENTION=1000
      - ETCD_QUOTA_BACKEND_BYTES=4294967296
    volumes:
      - etcd_data:/etcd
    networks:
      - litchi-network
    restart: unless-stopped

  # Milvus 向量数据库依赖 - minio
  minio:
    image: minio/minio:RELEASE.2023-03-20T20-16-18Z
    container_name: litchi-minio
    environment:
      - MINIO_ACCESS_KEY=minioadmin
      - MINIO_SECRET_KEY=minioadmin
    volumes:
      - minio_data:/minio_data
    command: minio server /minio_data
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:9000/minio/health/live"]
      interval: 30s
      timeout: 20s
      retries: 3
    networks:
      - litchi-network
    restart: unless-stopped

  # Milvus 向量数据库
  milvus:
    image: milvusdb/milvus:v2.3.3
    container_name: litchi-milvus
    command: ["milvus", "run", "standalone"]
    environment:
      - ETCD_ENDPOINTS=etcd:2379
      - MINIO_ADDRESS=minio:9000
    volumes:
      - milvus_data:/var/lib/milvus
    depends_on:
      - "etcd"
      - "minio"
    ports:
      - "19530:19530"
    networks:
      - litchi-network
    restart: unless-stopped

  # Ollama 大模型服务
  ollama:
    image: ollama/ollama:latest
    container_name: litchi-ollama
    ports:
      - "11434:11434"
    volumes:
      - ollama_data:/root/.ollama
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
    networks:
      - litchi-network
    restart: unless-stopped

  # 后端服务
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: litchi-backend
    ports:
      - "8080:8080"
    environment:
      - NEO4J_URI=bolt://neo4j:7687
      - NEO4J_USER=${NEO4J_USER:-neo4j}
      - NEO4J_PASSWORD=${NEO4J_PASSWORD:-litchi123456}
      - MILVUS_HOST=milvus
      - MILVUS_PORT=19530
      - OLLAMA_URL=http://ollama:11434
      - OLLAMA_MODEL=${OLLAMA_MODEL:-qwen2.5:7b}
      - SPRING_PROFILES_ACTIVE=${SPRING_PROFILES_ACTIVE:-prod}
    depends_on:
      - neo4j
      - milvus
      - ollama
    networks:
      - litchi-network
    restart: unless-stopped

  # 前端服务
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: litchi-frontend
    ports:
      - "80:80"
    depends_on:
      - backend
    networks:
      - litchi-network
    restart: unless-stopped

volumes:
  neo4j_data:
  neo4j_logs:
  etcd_data:
  minio_data:
  milvus_data:
  ollama_data:

networks:
  litchi-network:
    driver: bridge
```

## 5. 常用命令

### 5.1 服务管理

```bash
# 启动所有服务
docker-compose up -d

# 停止所有服务
docker-compose down

# 重启服务
docker-compose restart

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f backend
```

### 5.2 数据管理

```bash
# 备份Neo4j数据
docker-compose exec neo4j neo4j-admin dump --to=/data/backup.dump

# 恢复Neo4j数据
docker-compose exec neo4j neo4j-admin load --from=/data/backup.dump

# 备份所有数据卷
docker run --rm -v litchi-qa-platform_neo4j_data:/data -v $(pwd):/backup alpine tar czf /backup/neo4j_backup.tar.gz /data
```

### 5.3 模型管理

```bash
# 进入Ollama容器
docker-compose exec ollama bash

# 拉取模型
ollama pull qwen2.5:7b

# 列出已安装模型
ollama list

# 删除模型
ollama rm qwen2.5:7b
```

## 6. 故障排查

### 6.1 服务无法启动

```bash
# 查看服务状态
docker-compose ps

# 查看错误日志
docker-compose logs

# 检查端口占用
netstat -tulpn | grep -E '7474|7687|19530|11434|8080|80'
```

### 6.2 Neo4j连接失败

- 检查Neo4j服务是否启动: `docker-compose ps neo4j`
- 检查认证信息: `NEO4J_AUTH` 环境变量
- 访问Neo4j控制台: http://localhost:7474 测试连接

### 6.3 Ollama模型加载失败

- 检查GPU是否可用: `nvidia-smi`
- 检查Ollama日志: `docker-compose logs ollama`
- 手动拉取模型: `docker-compose exec ollama ollama pull qwen2.5:7b`

### 6.4 内存不足

- 调整Neo4j内存配置: `NEO4J_dbms_memory_heap_max__size`
- 使用量化模型: `qwen2.5:7b-q4_K_M`
- 增加系统交换空间

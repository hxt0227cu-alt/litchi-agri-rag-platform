## 2. 核心模块设计

### 2.1 问答模块

#### 2.1.1 问答流程

```
用户提问
    ↓
[向量化] → bge-m3 嵌入
    ↓
[向量检索] → Milvus 检索 Top-K 文档
    ↓
[图谱检索] → Neo4j 查询相关实体和关系
    ↓
[Prompt 构建] → RAG + 知识图谱 融合
    ↓
[LLM 生成] → Qwen2.5-7B 生成答案
    ↓
[答案返回] → 前端展示
```

#### 2.1.2 核心类设计

```java
@Service
public class ChatService {
    
    @Autowired
    private KnowledgeGraphService kgService;
    
    @Autowired
    private VectorSearchService vectorSearchService;
    
    @Autowired
    private LLMService llmService;
    
    public ChatResponse processChat(ChatRequest request) {
        // 1. 向量化用户问题
        float[] questionVector = vectorSearchService.encodeText(request.getQuestion());
        
        // 2. 向量检索
        List<SearchResult> vectorResults = vectorSearchService.search(
            questionVector, 5, "litchi_knowledge"
        );
        
        // 3. 知识图谱检索
        KnowledgeGraphResult kgResult = kgService.queryByText(request.getQuestion());
        
        // 4. 构建增强Prompt
        String prompt = buildEnhancedPrompt(
            request.getQuestion(), vectorResults, kgResult
        );
        
        // 5. 调用大模型
        String answer = llmService.generate(prompt);
        
        // 6. 返回结果
        return ChatResponse.builder()
            .answer(answer)
            .knowledgeGraph(kgResult.getVisualizationData())
            .build();
    }
}
```

### 2.2 知识图谱模块

#### 2.2.1 实体类型设计

| 实体类型 | 属性 | 说明 |
|---------|------|------|
| LitchiVariety | name, origin, taste, ripeningSeason, yield | 荔枝品种 |
| Disease | name, symptom, cause, highSeason | 病害 |
| Pest | name, damage, controlMethod | 虫害 |
| Pesticide | name, type, usage, safetyInterval | 农药 |
| CultivationTechnique | name, description, bestSeason | 栽培技术 |

#### 2.2.2 关系类型设计

| 关系类型 | 起点 | 终点 | 说明 |
|---------|------|------|------|
| HAS_DISEASE | LitchiVariety | Disease | 品种易患病害 |
| HAS_PEST | LitchiVariety | Pest | 品种易患虫害 |
| TREATS | Pesticide | Disease/Pest | 农药防治对象 |
| PREVENTS | Pesticide | Disease/Pest | 农药预防对象 |
| NEEDS_TECHNIQUE | LitchiVariety | CultivationTechnique | 品种需要的技术 |

### 2.3 图像识别模块

#### 2.3.1 识别流程

```
用户上传图片
    ↓
[图片预处理] →  resize、归一化
    ↓
[YOLOv8 推理] → 目标检测
    ↓
[结果解析] → 提取检测框和类别
    ↓
[知识图谱查询] → 查询防治方法
    ↓
[返回结果] → 病害类型 + 置信度 + 防治建议
```

#### 2.3.2 支持的病害类型

| 类别ID | 病害名称 |
|--------|---------|
| 0 | 霜疫霉病 |
| 1 | 炭疽病 |
| 2 | 酸腐病 |
| 3 | 丛枝病 |
| 4 | 椿象虫害 |
| 5 | 正常叶片 |
| 6 | 正常果实 |

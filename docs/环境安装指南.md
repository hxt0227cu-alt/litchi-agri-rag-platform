## 1. 基础开发工具安装

### 1.1 Git 安装

#### Windows
1. 访问 [Git官网](https://git-scm.com/download/win)
2. 下载 Windows 安装包
3. 运行安装程序，使用默认配置即可
4. 安装完成后，打开 PowerShell 验证：
```powershell
git --version
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install git -y
git --version
```

#### 配置 Git
```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

## 2. Docker 环境安装

### 2.1 Windows 安装 Docker Desktop

1. 访问 [Docker官网](https://www.docker.com/products/docker-desktop)
2. 下载 Docker Desktop for Windows
3. 运行安装程序
4. 安装完成后重启电脑
5. 启动 Docker Desktop
6. 验证安装：
```powershell
docker --version
docker-compose --version
```

### 2.2 Linux 安装 Docker

#### Ubuntu/Debian
```bash
# 更新包索引
sudo apt update

# 安装依赖
sudo apt install apt-transport-https ca-certificates curl software-properties-common -y

# 添加 Docker GPG 密钥
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

# 添加 Docker 仓库
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装 Docker
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io -y

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 将当前用户添加到 docker 组
sudo usermod -aG docker $USER

# 验证安装
docker --version
docker-compose --version

# 注销并重新登录，使组权限生效
```

### 2.3 (可选) NVIDIA GPU 支持

#### Windows
1. 安装 [NVIDIA 显卡驱动](https://www.nvidia.com/geforce/drivers/)
2. Docker Desktop 已内置 WSL2 GPU 支持

#### Linux
```bash
# 安装 NVIDIA Container Toolkit
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

sudo apt update
sudo apt install nvidia-container-toolkit -y

# 配置 Docker
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker

# 验证 GPU 支持
docker run --rm --gpus all nvidia/cuda:11.8.0-base-ubuntu22.04 nvidia-smi
```

## 3. Java 开发环境

### 3.1 安装 JDK 17

#### Windows
1. 访问 [Oracle JDK 17](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html) 或 [OpenJDK 17](https://adoptium.net/)
2. 下载 Windows x64 安装包
3. 运行安装程序
4. 配置环境变量：
   - 新建系统变量 `JAVA_HOME`，值为 JDK 安装路径（如 `C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot`）
   - 编辑 `Path` 变量，添加 `%JAVA_HOME%\bin`
5. 验证安装：
```powershell
java -version
javac -version
```

#### Linux (Ubuntu/Debian)
```bash
# 安装 OpenJDK 17
sudo apt update
sudo apt install openjdk-17-jdk -y

# 验证安装
java -version
javac -version

# 配置 JAVA_HOME (可选)
echo 'export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64' >> ~/.bashrc
source ~/.bashrc
```

### 3.2 安装 Maven (可选)

项目使用 Spring Boot，通常使用 Maven Wrapper (`mvnw`)，无需单独安装 Maven。如需安装：

#### Windows
下载 [Maven](https://maven.apache.org/download.cgi)，解压并配置环境变量。

#### Linux
```bash
sudo apt install maven -y
mvn -version
```

## 4. Node.js 前端环境

### 4.1 安装 Node.js 18+

#### Windows
1. 访问 [Node.js官网](https://nodejs.org/)
2. 下载 LTS 版本（推荐 18.x 或 20.x）
3. 运行安装程序
4. 验证安装：
```powershell
node --version
npm --version
```

#### Linux (Ubuntu/Debian)
```bash
# 使用 NodeSource 仓库安装
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install nodejs -y

# 验证安装
node --version
npm --version

# (可选) 安装 nrm 管理 npm 镜像源
sudo npm install -g nrm
nrm use taobao
```

### 4.2 安装 Vue CLI (可选)
```bash
npm install -g @vue/cli
vue --version
```

## 5. Python 模型训练环境

### 5.1 安装 Python 3.9+

#### Windows
1. 访问 [Python官网](https://www.python.org/downloads/)
2. 下载 Python 3.9 或更高版本
3. 运行安装程序，**勾选 "Add Python to PATH"**
4. 验证安装：
```powershell
python --version
pip --version
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv -y

# 验证安装
python3 --version
pip3 --version
```

### 5.2 创建虚拟环境 (推荐)

#### Windows
```powershell
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
.\venv\Scripts\Activate.ps1

# 退出虚拟环境
deactivate
```

#### Linux
```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 退出虚拟环境
deactivate
```

### 5.3 安装 PyTorch、YOLOv8 和 edge-tts

#### 安装 PyTorch
访问 [PyTorch官网](https://pytorch.org/get-started/locally/) 获取适合你系统的安装命令。

**CPU 版本**:
```bash
pip install torch torchvision torchaudio
```

**GPU 版本 (CUDA 11.8)**:
```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```

#### 安装 YOLOv8
```bash
pip install ultralytics
```

#### 安装 edge-tts (语音合成)
```bash
pip install edge-tts
```

#### 验证安装
```python
import torch
import ultralytics
import edge_tts

print(f"PyTorch version: {torch.__version__}")
print(f"CUDA available: {torch.cuda.is_available()}")
print(f"Ultralytics version: {ultralytics.__version__}")
print(f"edge-tts installed: {hasattr(edge_tts, 'Communicate')}")
```

## 6. 大模型与向量环境

### 6.1 Ollama 大模型服务

#### Windows 安装
1. 访问 [Ollama官网](https://ollama.com/)
2. 下载 Windows 安装包
3. 运行安装程序
4. 验证安装：
```powershell
ollama --version
```

#### Linux 安装
```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama --version
```

#### 拉取 Qwen2.5-7B 模型
```bash
ollama pull qwen2.5:7b
```

#### 验证模型
```bash
ollama run qwen2.5:7b
```

### 6.2 bge-m3 向量嵌入模型

#### 下载模型
```bash
# 方法1: 使用 Hugging Face
pip install huggingface_hub
python -c "
from huggingface_hub import snapshot_download
snapshot_download('BAAI/bge-m3', local_dir='./models/bge-m3')
"

# 方法2: 使用 ModelScope (国内推荐)
pip install modelscope
python -c "
from modelscope import snapshot_download
snapshot_download('AI-ModelScope/bge-m3', cache_dir='./models')
"
```

### 6.3 YOLOv8-litchi 病害识别模型

#### 放置模型文件
将训练好的 `yolov8-litchi.pt` 模型文件放置在 `./models/` 目录下。

#### 验证模型
```python
from ultralytics import YOLO

model = YOLO('./models/yolov8-litchi.pt')
print("YOLOv8-litchi model loaded successfully")
```

## 7. IDE 配置

### 7.1 IntelliJ IDEA (后端开发)

1. 下载 [IntelliJ IDEA Community Edition](https://www.jetbrains.com/idea/download/)
2. 安装并启动 IDEA
3. 配置 JDK：
   - File → Project Structure → Project → SDK
   - 选择已安装的 JDK 17
4. 安装推荐插件：
   - Spring Boot Helper
   - Lombok
   - MyBatis Plugin

### 7.2 VS Code (前端开发)

1. 下载 [VS Code](https://code.visualstudio.com/)
2. 安装推荐插件：
   - Volar (Vue 3 支持)
   - TypeScript Vue Plugin
   - ESLint
   - Prettier
   - GitLens

## 常见问题

### Q: Docker Desktop 启动失败？
A: 确保已启用 WSL2 和虚拟化功能。

### Q: Java 版本不匹配？
A: 使用 `java -version` 检查版本，确保是 JDK 17+。

### Q: npm install 速度慢？
A: 配置淘宝镜像：`npm config set registry https://registry.npmmirror.com`

### Q: PyTorch GPU 不可用？
A: 检查 NVIDIA 驱动和 CUDA 版本是否匹配。

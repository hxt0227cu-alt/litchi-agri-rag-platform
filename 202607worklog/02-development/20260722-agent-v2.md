# 2026-07-22 Agent V2 开发记录

## 已完成

- 新增 `/api/v1/agent-runs` 异步入口、状态查询、SSE 事件、取消和审批接口。
- Agent 运行在 MySQL 可用时持久化，故障时回退内存；终态通过 Outbox 记录领域事件。
- 新增 Agent Prometheus 指标和 Python 诊断服务指标。
- 新增风险策略：用药/剂量、证据不足、工具失败和模型降级标记为高风险。
- 新增果园档案 API 与前端页面，Agent 可读取果园上下文。

## 关键问题

Agent 的异步任务可能在用户订阅 SSE 前完成，因此接口同时保留状态查询，前端使用轮询兜底。运行记录按用户隔离；租户字段已进入数据表和事件契约，认证主体的真实租户绑定将在下一阶段补齐。

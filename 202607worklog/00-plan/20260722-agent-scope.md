# 2026-07-22 AI Agent 范围

## 目标

在现有 RAG 问答之外增加可审计的领域任务智能体，展示任务规划、工具调用、权限治理、降级和轨迹追踪能力。

## 第一版边界

- 只开放知识库、知识图谱和方案推荐三个只读工具。
- 最多执行 4 步，每个工具每次运行最多调用一次。
- 不支持代码执行、任意网络访问和自动业务写入。
- 农户和技术员可通过前端使用；服务端根据登录角色二次过滤工具。
- 运行记录暂存进程内存，后续生产化阶段迁移 MySQL。

## 验收

- 模型能够返回合法计划时，执行对应白名单工具。
- 模型输出非法工具或无效 JSON 时，使用安全的确定性计划。
- 未授权角色无法调用方案推荐工具。
- 响应展示步骤、状态、耗时、规划模式、降级状态和最终结论。

# ADR-001：采用受限工具 Agent，而非开放式 ReAct

- 日期：2026-07-22
- 状态：已采纳

## 决策

采用 Planner、权限过滤、顺序执行、结果综合四阶段架构。模型只负责选择服务端白名单工具，不能生成并执行代码、URL 或数据库语句。

## 原因

农业诊疗涉及用药与业务协同，开放式工具调用的提示词注入、越权写入和不可预测成本不可接受。受限工具仍能展示 Agent 的规划与编排价值，同时每一步都可测试、计量和审计。

## 权衡

该方案牺牲部分自主性，换取确定的权限边界、延迟上限和故障行为。后续写工具必须通过人工确认状态机扩展，而不是放宽现有执行器。

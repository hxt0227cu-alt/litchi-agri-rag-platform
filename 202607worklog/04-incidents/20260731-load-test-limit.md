# 2026-07-31 本机负载测试未达标

## 现象

- 100 并发、200 个聊天请求、15 秒超时。
- 首次测试成功率 50.5%，P95 15.03 秒。
- 修复旧接口路径和 PowerShell 5 兼容性后，增加外部依赖快速失败窗口，并调整本地文档读取并发。
- 复测成功率 19%，P95 15.18 秒，仍未达到验收目标。
- 最后一组 50 并发测试在 3 分钟内未完成，被主动终止。

## 已确认问题

1. 压测脚本仍使用旧路径 `/chat` 与 `/diagnosis`，已迁移为 `/chats` 与 `/diagnoses`。
2. Windows PowerShell 5 缺少 `System.Text.Json.dll`，负载生成器已移除该依赖。
3. 外部依赖不可用时存在重复探测，已增加短期快速失败保护。
4. 文档检索曾使用对象级同步，已改用读优化的 `CopyOnWriteArrayList`。

## 未解决

修复后 100 并发仍不达标，推测仍有同步状态持久化、线程池占用或请求侧排队问题。根据本轮时间边界停止继续调优，避免用未经证实的结论替代分析。
